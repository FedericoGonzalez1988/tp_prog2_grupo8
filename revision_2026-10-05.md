### 2.2 Build

| Paso            | Resultado                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------- |
| `npm run lint`  | ❌ 32 errores (largo de línea, modificadores de acceso, números mágicos, variables sin usar) |
| `tsc`           | ❌ 18 errores                                                                                |
| `npm run build` | ❌ Falla                                                                                     |

Causas de los errores de compilación:

- Se importan `./estado` y `./estacion`, pero esos archivos **no existen**.
- Faltan `import` de `Empleado`, `Pedido`, `Comida` y `Mesa` en varios archivos.
- `Mozo.agregarItem()` hace `pedido.push(item)`, pero `pedido` es un `Salon`, no un array.
- `ParaLlevar` llama a `super()` sin los parámetros que requiere `Pedido`.
- `Pedido.agregarProducto()` accede a `producto.disponible`, que es privado (debería usar `getDisponible()`).
